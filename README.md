# Flex-o-Stool
Die Website des Flex-o-Stool soll dazu dienen, seine Funktionalitäten zu verdeutlichen. Die Entwicklung wurde von Amelie Pohl durchgeführt und auf Anfrage kann ein ausführliches Dokument mit weiteren Inhalten zur Verfügung gestellt werden. 
## Website
Die Website wurde zum Großteil mittels Google-Gemini und innerhalb weniger Stunden erstellt. Die Website ist [hier](https://leno27.github.io/Flex-o-Stool/) zu finden. Die Nutzung ist auf PC und Mobilen Geräten möglich, das Nutzungsformat ist jedoch für zweiteres optimiert.
